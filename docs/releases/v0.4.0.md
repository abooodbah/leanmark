# LeanMark v0.4.0

LeanMark 0.4.0 lets you expand any diagram or figure to the full window and
zoom it, steps page zoom through fixed levels, and speeds up the parser core
that every platform shares.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.4.0-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.4.0-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.4.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## Highlights

- **Expand diagrams and figures.** Every Mermaid diagram and standalone image
  has a small, semi-transparent expand button in its bottom-right corner. It
  opens the figure full-window, fitted to the window and drawn in the reader's
  theme. In the viewer:
  - + and - zoom from 10% to 800%, also with Ctrl or Command held;
  - 0 fits the figure to the window, 1 shows its actual size, and a
    double-click switches between the two;
  - the arrow keys, a drag, or the scroll wheel pan, and Ctrl+wheel zooms at
    the pointer;
  - Escape, the close button, or a click on the background closes it and
    returns focus to the figure.
- **Page zoom levels.** Ctrl++ (or Ctrl+=), Ctrl+-, and Ctrl+0 (Command on
  macOS) now step through 50, 67, 75, 80, 90, 100, 110, 125, 150, 175, 200,
  250, and 300%. The new level shows briefly, and LeanMark remembers it for the
  next launch.
- **A faster core.** On a 22.8 MiB document, rendering went from 177.7 to
  135.4 ms, preparing the page message from 88.3 to 38.8 ms, and copying the
  whole document from 105.2 to 3.7 ms. The rendered HTML now takes 34.3 MiB
  instead of 53.0 MiB, and the Linux and macOS hosts no longer keep it once
  the page has it.
- With "show animations" turned off in Windows, macOS, or the Linux desktop,
  Mermaid diagrams could be laid out at the wrong size. They now render the
  same as with animations on.
- Documents with more than 50 Mermaid diagrams no longer render the extra
  diagrams behind their "limit reached" message.

## Installing

On Windows, `winget upgrade abooodbah.LeanMark` (or `winget install` for a
first install) picks up 0.4.0 once the winget community repository has
accepted the new manifest, which can take a few days after this release.
The ZIP below is available immediately.

## Platform notes

### Windows

The Windows ZIP remains portable and includes optional per-user integration.
The executable is unsigned, so Windows may report an unknown publisher or show
a Microsoft Defender SmartScreen warning. The Evergreen WebView2 Runtime is
required. The saved zoom level is stored next to the theme under
`HKCU\Software\LeanMark`.

### Linux

The Debian package targets Ubuntu 24.04 and compatible x86-64 distributions.
GTK 4 and WebKitGTK 6.0 runtime dependencies are declared by the package. The
saved zoom level is stored in `~/.config/leanmark/settings.ini`.

### macOS preview

The ZIP contains a Universal 2 preview for Intel and Apple silicon. It is
ad-hoc signed and not Apple-notarized, so Gatekeeper may require an explicit
approval in **System Settings > Privacy & Security**. The SHA-256 sidecar
verifies that the downloaded bytes match this GitHub Release; it does not
establish publisher identity.

## Efficiency note

The core timings are best-of-five runs on Linux x86-64 with GCC 13, using a
generated document made of the README and the showcase fixture repeated. The
README's Windows process-tree figures were measured for 0.3.0 and have not
been re-measured for this release.
