# LeanMark v0.5.0

LeanMark 0.5.0 adds two softer dark themes, Dim and Dusk, for long reading
with less contrast than Dark. They were requested in issue #6.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.5.0-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.5.0-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.5.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## New

- **Dim**, a neutral dark grey: page `#1e2023`, text `#c8ccd2`.
- **Dusk**, a warm dark: page `#221e19`, text `#d4c8b4`.

The theme button in the toolbar, or Ctrl+Shift+T, now steps through System,
Light, Dark, Dim and Dusk, and LeanMark remembers the choice. On macOS the
Cycle Theme command uses the same order. Mermaid diagrams take the theme's
own colours in Dim and Dusk. On Windows the window background, the title bar
and the WebView2 start colour follow the new themes, so they open without a
white flash.

Body text contrast is 10.1 to 1 in Dim and 10.0 to 1 in Dusk, against 18.5 to
1 in Dark; every text colour in the two themes meets WCAG AA (4.5 to 1).

## How it was measured

On Windows, with the same document and the Dark theme saved, peak memory was
125.8 to 126.3 MiB against 126.3 to 128.1 MiB for 0.4.2, and the rendered
document appeared in a median 900.5 ms against 909.8 ms. The Windows package
is 13.6 KB larger. The Windows, Linux and macOS test suites pass.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the downloaded-file mark once from the extracted
folder with `Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.5.0 once the winget community
repository has accepted the new manifest.

## Known gaps

- Dark's find highlights are below WCAG AA (3.1 and 3.9 to 1). Dark itself is
  unchanged in this release.
- On Linux and macOS the window does not paint the theme background before the
  page draws, for any theme, so a brief flash at launch is still possible.
- The macOS preview remains ad-hoc signed and not notarized, so Gatekeeper may
  require an explicit approval in **System Settings > Privacy & Security**.
