# LeanMark v0.7.0

LeanMark 0.7.0 marks the section you are reading in "On this page", fixes a
slow resize that came with 0.6.0, and opens documents with many repeated
headings faster.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.7.0-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.7.0-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.7.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## New

- **Current section in "On this page".** As you scroll, the outline marks
  the section you are reading, and keeps that entry in view when the outline
  is taller than the window. The entry gets the theme's muted background, a
  bar in the link colour and the main text colour, in System, Light, Dark,
  Dim and Dusk. With Windows high contrast it is underlined. Screen readers
  hear it as the current location. A clicked entry stays marked until you
  scroll on.

## Fixed

- Resizing the window into or out of the narrow layout laid the page out
  twice since 0.6.0. On a 1 MiB file in Chrome, a resize from 1000 to 700 px
  went from 1,375 to 962 ms.
- On Linux each theme change drew every Mermaid diagram twice.

## Faster

- Documents with many repeated headings open faster: on an 8 MiB file with
  326 copies of each heading, the reader's open script went from 1,001 to
  493 ms. Heading ids, and so links to them, stay the same.
- A theme change no longer redraws diagrams when their colours stay the
  same, for example System to Light on a light system.

## How it was measured

In the `launch-time` workflow on Windows (run 42178492623), the document was
ready in a median 573.3 ms for simple.md and 700.9 ms for showcase.md,
against 572.0 ms and 712.0 ms for v0.6.0. With an 8 MiB file open, peak
working set was 1,779.8 MiB against 1,759.0 MiB (1.2% more, inside the
spread of repeated runs of the same build). LeanMark.exe is 457,216 bytes in
both; the Windows files are 8,535 bytes larger.

On Linux, start to the smoke-test check took a median 421.5 ms against
422.1 ms for 0.6.0, and peak memory with the 8 MiB file was 1,343.1 MiB
against 1,408.5 MiB. The Windows, Linux and macOS test suites pass. macOS
was not timed.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the downloaded-file mark once from the extracted
folder with `Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.7.0 once the winget community
repository has accepted the new manifest.

## Known gaps

- The last sections, whose headings cannot scroll up to the reading line,
  are marked only when you click them in the outline.
- On a very long outline (over 10,000 entries) the mark adds about 1 ms of
  work per scroll step.
- Windows and macOS were tested in CI, not by hand, for this release.
- The macOS preview remains ad-hoc signed and not notarized, so Gatekeeper may
  require an explicit approval in **System Settings > Privacy & Security**.
