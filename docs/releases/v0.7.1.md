# LeanMark v0.7.1

LeanMark 0.7.1 fixes the reading column of short documents in wide windows.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.7.1-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.7.1-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.7.1-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## Fixed

- A document with fewer than two second- or third-level headings has no
  "On this page" outline. In a window 1180 px wide or wider, its text was
  shown in a column only 220 px wide, the width of the missing outline, with
  empty space beside it. The text width setting made no difference. It now
  gets the Narrow, Wide or Full column like any other document. Documents
  with an outline look the same as before.

It was reported on 6 November 2026 with a short status note (one title,
four paragraphs and a diagram) in a maximised window. The layout rule dates
from 0.1.0, so every earlier release has it.

## What changed

The wide layout has three columns: the outline, the text, and an empty
column of the same width on the other side. A document without an outline
hid the outline but kept the three columns, so the text went into the
first, 220 px one. The reader now marks the page when the document has an
outline, and uses the three columns only then (#35).

## How it was measured

In the `launch-time` workflow on Windows (run 42245348765), the document was
ready in a median 573.6 ms for simple.md and 573.1 ms for showcase.md,
against 578.8 ms and 569.4 ms for v0.7.0. With an 8 MiB file open, peak
working set was 1,827.7 MiB against 1,828.1 MiB. LeanMark.exe is 457,216
bytes in both; the Windows files are 461 bytes larger.

The column was checked in the Windows app itself, from a CI build of the
fix, with a made-up document of the same shape and with the reported file:
in a 1,900 px window the text column went from 220 px to 720 px (Narrow).

The reader browser test now opens a document without an outline in each
text width at 760, 761, 966, 1179, 1180 and 1880 px and checks the column
width and that it is centred. The Windows, Linux and macOS test suites
pass.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the downloaded-file mark once from the extracted
folder with `Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.7.1 once the winget community
repository has accepted the new manifest.

## Known gaps

- The real-app (WebView2) layout check is not part of CI; it was run by hand
  on Windows 11 for this fix. Linux and macOS were tested in CI only.
- Launch time was measured on Windows only.
- The macOS preview remains ad-hoc signed and not notarized, so Gatekeeper may
  require an explicit approval in **System Settings > Privacy & Security**.
