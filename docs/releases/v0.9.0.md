# LeanMark v0.9.0

LeanMark 0.9.0 typesets math formulas offline and can show its interface in
Japanese.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.9.0-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.9.0-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.9.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release, and a
build provenance attestation (`gh attestation verify <file> --repo
abooodbah/leanmark`).

## New

- **Math.** TeX between `$...$` (inline) and `$$...$$` (display) is
  typeset with KaTeX 0.19.1, bundled with the app, on Windows, Linux and
  macOS. KaTeX loads only for a document that contains math, so other
  documents open as before. A price such as "$5 to $10" stays text. A formula
  KaTeX cannot read keeps its source, shown in the theme's danger colour.
  Find counts a word inside a formula once, and screen readers get the
  formula's MathML (#47).
- **Japanese interface.** Windows shows it when the display language is
  Japanese, and the settings panel's Language choice now lists 日本語 next
  to System, English and 简体中文. Everything the Chinese interface covers is
  translated: the toolbar, settings panel, shortcut list, start page, diagram
  and image messages, the app's status and error messages, the file dialog
  and the start-up error boxes. The page marks itself as Japanese, so Windows
  draws it with a Japanese font (#48).
- The README has a short 日本語 section, and both the Chinese and Japanese
  sections mention math.

## Settings

Settings saved by 0.8.0 read the same. 0.8.0 reads a saved Japanese choice
as System.

## How it was measured

In the Compare launch time workflow on Windows (run 45364373039), with an
English runner, the document was ready in a median 577.9 ms for simple.md
and 587.2 ms for showcase.md, against 583.8 ms and 585.2 ms for v0.8.0.
With an 8 MiB file open, peak private memory was 1,553.4 MiB against
1,546.8 MiB. LeanMark.exe is the same size; the Windows files grow by
576,746 bytes, almost all of it KaTeX and its fonts, which load only for a
document with math. On a Windows 11 laptop, a document with math used
12.6 MiB more peak private memory than the same text without it, and its
formulas were typeset in about 33 ms. The Windows, Linux and macOS test
suites pass.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the downloaded-file mark once from the extracted
folder with `Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.9.0 once the winget community
repository has accepted the new manifest.

## Known gaps

- The Japanese translation was checked by back-translation with Google
  Translate, not yet by a native speaker.
- On Linux and macOS the page follows the system language, but there is no
  Language choice, and the menus and dialogs stay English.
- Text inside Mermaid diagrams, the WebView2 context menu, the Store
  listing, the website and the installer scripts are in English.
- Math needs the `$` delimiters; `\(...\)` and `\[...\]` are not read as
  math. Two dollar signs in ordinary text, outside code marks, can be read
  as a formula, as on GitHub; code marks keep such text as it is.
- macOS was tested in CI only. The macOS preview remains ad-hoc signed and not
  notarized, so Gatekeeper may require an explicit approval in **System
  Settings > Privacy & Security**.
