# LeanMark v0.8.0

LeanMark 0.8.0 can show its interface in Simplified Chinese on Windows.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.8.0-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.8.0-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.8.0-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## New

- **Simplified Chinese interface.** Windows shows it when the display
  language is Simplified Chinese (zh-CN, zh-SG, zh-Hans). The settings panel
  has a Language choice: System, English, or 简体中文, saved like the theme.
  The toolbar, settings panel, shortcut list, start page, diagram and image
  messages, the app's status and error messages, the file dialog, and the
  start-up error boxes are translated. English stays the fallback for any
  string without a translation (#40).
- The README has a short 简体中文 section.

## Changed

- The Microsoft Store now lists the app as LeanMark Markdown Viewer. The
  program, its window title and the winget, Scoop, Chocolatey and Homebrew
  package names stay LeanMark (#41).

## Settings

Settings saved by 0.7.1 have no language, so LeanMark follows the Windows
display language and an English Windows sees no change. 0.7.1 ignores the
Language value that 0.8.0 saves.

## How it was measured

In the Compare launch time workflow on Windows (run 43810330916), with an
English runner, the document was ready in a median 577.4 ms for simple.md
and 731.8 ms for showcase.md, against 571.4 ms and 736.2 ms for v0.7.1.
With an 8 MiB file open, peak private memory was 1,606.8 MiB against
1,602.8 MiB. LeanMark.exe grows by 9,216 bytes and the Windows files by
38,961 bytes, mostly the Chinese strings. The Windows, Linux and macOS test
suites pass.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the downloaded-file mark once from the extracted
folder with `Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.8.0 once the winget community
repository has accepted the new manifest.

## Known gaps

- The translation has not been reviewed by a native speaker yet.
- Traditional Chinese (zh-TW, zh-HK, zh-MO, zh-Hant) keeps English.
- On Linux and macOS the page follows the system language, but there is no
  Language choice, and the menus and dialogs stay English.
- Text inside Mermaid diagrams, the WebView2 context menu, the Store
  listing, the website and the installer scripts are in English.
- The Chinese interface was checked by the tests, not yet by hand in the
  Windows app. macOS was tested in CI only.
- The macOS preview remains ad-hoc signed and not notarized, so Gatekeeper may
  require an explicit approval in **System Settings > Privacy & Security**.
