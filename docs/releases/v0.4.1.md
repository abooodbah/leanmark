# LeanMark v0.4.1

LeanMark 0.4.1 fixes slow launches of a LeanMark installed from a downloaded
ZIP on Windows, and an installer that stopped when LeanMark was open.

## Release assets

| Platform | Artifact |
| --- | --- |
| Windows x64 | **LeanMark-v0.4.1-windows-x64.zip** |
| Ubuntu 24.04 / Debian-compatible x86-64 | **LeanMark-v0.4.1-linux-x86_64.deb** |
| macOS Intel and Apple silicon | **LeanMark-v0.4.1-macos-universal-preview.zip** |

Every artifact has an adjacent **.sha256** sidecar in this release.

## Fixes

- **Faster launches after installing from a download.** Explorer marks every
  file extracted from a downloaded ZIP as coming from the internet. The
  installer copied that mark onto the installed files, and because
  `LeanMark.exe` is unsigned, Windows checked it before every launch from a
  `.md` double-click or the Start menu. The installer now clears the mark on the
  installed copy only; the downloaded folder keeps it. Running the 0.4.1
  installer over an existing installation applies the fix.
- **Installing over an open LeanMark.** The installer stopped with
  "The process cannot access the file ... because it is being used by another
  process" when LeanMark was open from the install directory. The installer
  and the uninstaller now ask that window to close, wait up to ten seconds, and
  otherwise stop with a clear message before changing anything.

## How it was measured

A new Windows workflow rebuilds 0.3.0, 0.4.0, and 0.4.1 with the same test
hook and times launches to a rendered document, taking turns. Without the
download mark the three are equal: about 570 ms for a short document and
700 ms for the diagram showcase, of which about 350 ms is the host and WebView2
starting. Started through the shell with the mark, the unsigned executable is
held for Windows' check instead. A new CI test installs a package marked as
downloaded, checks that no installed file keeps the mark, and starts the
installed copy through the shell.

## Installing

On Windows, run the installer from the extracted ZIP:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\installer\install.ps1 -OpenDefaultAppsSettings
```

For a portable copy, clear the mark once from the extracted folder with
`Get-ChildItem -Recurse | Unblock-File`.

`winget upgrade abooodbah.LeanMark` picks up 0.4.1 once the winget community
repository has accepted the new manifest.

## Platform notes

The Linux and macOS packages carry no changes beyond the version number. The
macOS preview remains ad-hoc signed and not notarized, so Gatekeeper may
require an explicit approval in **System Settings > Privacy & Security**.
