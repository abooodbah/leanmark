The reading workflow

A document opens as a document.

LeanMark turns a Markdown file into a calm reading surface without project indexing, editor panes, extensions, or workspace management.

  • CommonMark plus GFM tables, tasks, autolinks, and strikethrough
  • Automatic outline, find, print, themes, and reading progress
  • Page zoom in fixed steps from 50% to 300%, remembered between launches
  • Relative local images and Markdown links
  • Live refresh after the file changes on disk

Offline diagrams

Mermaid stays with the document.

The release includes its Mermaid renderer. Diagrams work without an active connection, and the library is loaded only when the document contains a Mermaid fence.

LeanMark is explicit about its architecture: one portable C++ parser feeds native Win32, GTK, and AppKit hosts. Each host uses the operating system web runtime for selectable text, printing, images, and diagrams.

New in 0.4.0

Any diagram, as large as it needs to be.

A small button in the corner of every Mermaid diagram and image opens it across the whole window, fitted and sharp.

  • Zoom from 10% to 800% with + and -, or Ctrl+wheel at the pointer
  • 0 fits the window, 1 shows actual size, arrows and drag pan
  • Escape returns to the exact place in the document

Measured, not magical

Small package. Honest runtime cost.

System web runtimes stay outside LeanMark's packages, but renderer, GPU, and utility processes still use memory. Package size is not the same as total footprint.

The published figures below are a Windows 11/WebView2 baseline. Hardware, system state, runtime version, and document complexity affect results; Linux and macOS measurements are not inferred.

Practical guards

Local Markdown is treated as untrusted input.

LeanMark narrows what a document can do, then verifies those boundaries against hostile fixtures.

Read the security policy
  • Raw HTML disabledMD4C renders Markdown without activating embedded HTML.
  • Strict local page policyA Content Security Policy limits scripts and resources.
  • Remote content blockedRemote images, downloads, popups, and permissions are denied.
  • External links leave the readerHTTP, HTTPS, and mail links go to the operating-system handler only after a click.

Platform releases

Native packages for three desktops.

GitHub Releases provides a Windows x64 ZIP, an Ubuntu 24.04 / Debian-compatible x86-64 package, and one Universal 2 macOS preview for Intel and Apple silicon.

Transparent trust status. The GitHub Windows ZIP is unsigned, so Windows may show an unknown-publisher warning; the Microsoft Store build is signed by Microsoft. The macOS preview is ad-hoc signed and not notarized. Each package has a SHA-256 sidecar that verifies a byte-for-byte match; it does not establish publisher identity. The release notes document platform requirements.

Questions

Reading Markdown files on the desktop

How do I open an .md file on Windows?

Install LeanMark from the Microsoft Store, with winget install abooodbah.LeanMark, or from GitHub Releases, then open the file. Headings, tables, task lists, local images, and Mermaid diagrams render as a formatted page.

How do I read a Markdown file that Claude, ChatGPT, or a coding agent saved?

Open the .md file in LeanMark. When the file changes on disk, the page refreshes and keeps your approximate reading position, so you can keep it open while the file is being written.

Does it work offline?

Yes. Everything renders on your computer with bundled libraries and fonts. Remote images are not loaded, and LeanMark's own code makes no network requests. On Windows, the WebView2 runtime that draws the page can contact Microsoft on its own.

Can I edit Markdown?

No. LeanMark is a viewer. Use your editor to write and LeanMark to read.

Does it support Mermaid diagrams?

Yes, rendered offline by the bundled Mermaid library. Any diagram or image can be expanded to the full window, with zoom from 10% to 800% and panning.

Is LeanMark free?

Yes. It is MIT licensed and free on GitHub, the Microsoft Store, winget, Chocolatey, Scoop, and Homebrew.

How heavy is it?

Measured on Windows 11 with 0.3.0: about 74 ms to a visible window and about 97 MiB peak private memory for the whole app, including WebView2. The Windows application payload is 4.17 MiB. Linux and macOS are not measured yet.

Is raw HTML in a document run?

No. Raw HTML is disabled, and a strict Content Security Policy limits scripts and resources.

Privacy

Privacy policy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Network use

On Windows, LeanMark displays documents through Microsoft's Edge WebView2 runtime, which is not part of LeanMark. That runtime can contact Microsoft services on its own, as the README records, and its network use is governed by the Microsoft Privacy Statement.

Uninstall

On Windows, use Settings > Apps > Installed apps > LeanMark, delete the folder of a portable copy, or run winget uninstall abooodbah.LeanMark or choco uninstall leanmark. On Linux, run sudo apt remove leanmark. On macOS, move LeanMark.app to the Trash.

Built in public

Useful tools get better through real documents.

LeanMark is early, public, and MIT licensed. Compatibility reports based on real, non-private Markdown documents are welcome, especially documents containing Mermaid diagrams.
