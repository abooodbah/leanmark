How to view Mermaid diagrams offline

A Mermaid diagram is plain text in a Markdown code block that starts with ```mermaid. To see it as a drawing, you need a program that includes the Mermaid renderer. These are the common desktop options and how they differ.

In LeanMark

Open the file and read the diagram

LeanMark draws each mermaid code block as a diagram on your computer. The Mermaid library ships with the app and is loaded only when the document contains a Mermaid block.

  • No internet connection needed to draw a diagram
  • Mermaid runs in its strict security mode
  • The page reloads when the file changes on disk

Large diagrams

Make a diagram as large as it needs to be

Expand to the full window

A button in the corner of every Mermaid diagram opens it across the whole window, fitted to it. Escape returns to the same place in the document.

Zoom and pan

Zoom from 10% to 800% with + and -, or Ctrl+wheel at the pointer. 0 fits the window, 1 shows actual size, and arrow keys or dragging pan.
